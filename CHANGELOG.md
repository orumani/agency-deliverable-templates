# Changelog

## 1.0.0

First release.

- `deliverable.css`: one stylesheet with design tokens, eight category accents, and 30+ report components (executive summary, metrics, callouts, recommendation cards, status pills, SWOT, pros and cons, flow rows, tables), plus responsive and print rules.
- Six templates: blank, report, audit, strategy brief, monthly performance report, proposal.
- Examples: a filled website audit, a filled monthly report, and a component gallery.
- Full Engine only: four Claude Code skills (`new-report`, `produce-deliverable`, `verify-deliverable`, `ship-deliverable`), three standard-library Python scripts (scaffold, 30-check verifier, single-file packager), an installer, and a settings file.
